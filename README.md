# Pepo's Sauna — сайт бронирования

Профессиональный одностраничный сайт для бани/бассейна/шашлыка в Кобулети
(ул. Агмашенебели 738). Статический сайт без сервера — бронирование работает
через WhatsApp / Telegram / звонок.

## ✨ Что внутри
- 3 языка: **RU / EN / GE** (переключатель в шапке, запоминает выбор)
- Онлайн-бронирование с **живым расчётом цены** → заявка в WhatsApp/Telegram
- Карточки услуг (баня, бассейн, коттедж), галерея с просмотром, отзывы
- Акция с таймером, подарочные сертификаты, FAQ, карта, плавающие кнопки
- SEO: мета-теги, Open Graph, schema.org, sitemap, favicon
- Адаптив под телефон/планшет/десктоп, доступность, тёмная премиум-тема

## 🗂 Структура
```
index.html          — страница (трогать обычно не нужно)
css/styles.css      — оформление
js/config.js        — 👈 ВАШИ НАСТРОЙКИ: телефоны, цены, доп.услуги, ссылки, акция
js/i18n.js          — тексты на 3 языках
js/main.js          — логика (менять не нужно)
assets/img/         — фотографии
robots.txt, sitemap.xml, assets/favicon.svg
```

## ⚙️ Как редактировать

### Телефоны, цены и доп.услуги
Откройте **`js/config.js`** — это единственный файл для правок контента.
Там понятные подписи. Строки с `// TODO` нужно заполнить реальными данными:
- цены на **бассейн** и **коттедж** (сейчас стоят примерные);
- доплата за гостя сверх базового (`extraGuestPrice`), если есть;
- часы работы (`hours`);
- точная ссылка на карту (`mapLink`) и встраиваемая карта (`mapEmbed`).

Telegram: в поле `telegram` впишите ваш username (например `pepossauna`) или номер с `+`.

### Тексты (3 языка)
Откройте **`js/i18n.js`**. Для каждой строки есть три версии: `ru`, `en`, `ge`.
Меняйте текст — ключи оставляйте как есть.

### Фотографии
Замените файлы в **`assets/img/`** своими (те же имена — ничего больше менять не надо):
- `hero.jpg` — большое фото на главном экране (горизонтальное/вертикальное, качественное)
- `sauna.jpg`, `sauna-barrel.jpg`, `atmosphere.jpg` — баня/парная
- `features.jpg` — бассейн/территория
- `poster.jpg`, `promo-tigers.jpg` — промо
- `logo.jpg` — круглый логотип

### Акция
В `js/config.js` → `promo`. `enabled: false` убирает баннер.
`endsAt` — дата окончания для таймера. Текст акции — в `js/i18n.js` → `promo.text`.

## 🚀 Публикация (бесплатно)
Любой из вариантов:
- **Netlify / Cloudflare Pages / Vercel** — перетащите папку в веб-интерфейс, готово.
- **GitHub Pages** — залейте папку в репозиторий, включите Pages.
- Или загрузите файлы на ваш хостинг по FTP.

Это обычные файлы — специальной сборки не требуется.
